# Egress allowlist for the Routine's cloud environment.
#
# Paste the domains below (comment lines and blanks are ignored by the
# field; strip them if it will not take them) into claude.ai/code ->
# the cloud environment this Routine runs in -> Edit -> Network access
# -> Custom, with "also include the default list" ticked so package
# registries and GitHub keep working.
#
# WHY THIS FILE EXISTS: the prompt's own domain list says which sources to
# PREFER. It cannot grant access: the sandbox sits behind an egress proxy
# with its own allowlist, and anything absent from THAT list comes back as
# EGRESS_BLOCKED however the prompt is written. This file is the list to
# paste there, kept in step with the prompt by a test.
#
# WHAT IT COSTS: every domain here is somewhere a run that has just read a
# mailbox could send a request. That is why the list is finite and boring -
# quote sources, wire services, journals - with no wildcard, and why the
# prompt forbids putting anything from the mailbox into a request at all.
# Add a domain when a run actually needed it and was refused; not before.
#
# EVERY HOST IS LISTED IN FULL, INCLUDING www. The proxy matches the exact
# hostname, not the registered domain: with only "coingecko.com" listed, a
# fetch of www.coingecko.com still came back EGRESS_BLOCKED, while
# stockanalysis.com - which serves at the apex - went through. That is why
# each entry below appears twice where both hosts exist, and why there is
# still no wildcard: *.coingecko.com would also carry every other subdomain
# anyone can stand up there.
